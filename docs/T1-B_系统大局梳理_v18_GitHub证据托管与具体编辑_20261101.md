**根因（已坐实，非假设）** `finance_dss_backend/RemoteActions.js` 的 `tsAppendRows`：
- **:96–105 锁外**读已有 UUID 进 `exist{}`；
- **:108–117 锁外**据 `exist{}` 决定 `toWrite`（去重决策在锁外完成）；

→ 两并发请求都在 :96–105 读到"看不到对方在途行"的同一快照 → 都带相同新 UUID 进锁 → 都写出 → **重复行**。这是冗余"重放/再长"的工程根因。
