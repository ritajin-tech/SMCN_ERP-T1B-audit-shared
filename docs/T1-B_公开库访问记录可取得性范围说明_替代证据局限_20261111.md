## 三、替代证据局限（六条，不虚报、不夸大）

1. 🔴 **「查不到」不等于「无访问」**。本方只读通道只覆盖仓库**内容与元数据**，不覆盖「谁访问过、何时访问、从何地址、是否克隆或下载」。本方**不能据此确认存在或不存在任何第三方访问**。
2. 🔴 **403 / 无凭据是能力边界，不是事实结论**。`list_repository_collaborators` 的 403 与 traffic 端点无凭据，说明的是**本方集成权限不足**，不是仓库无协作者、不是仓库无访问记录，也不等于有权通道所有者已出具范围说明。

4. 🔴 **commit / issue / PR 列表不反映读取行为**。它们只反映仓库自身版本与议题，不反映匿名读取、clone、下载或被搜索引擎收录；「仅我方一条提交」不等于「仅我方访问过」。
5. 🔴 **本版脱敏只约束 v92 新增件**。按 Tom 本函「不要擅自改写或删除证据历史」，历史已推送的 git 对象**原样保留**；本方不 force push、不 filter-branch、不删历史对象、不改写历史正文。故本说明**不构成对历史公开内容的下线或脱敏**。
6. 🔴 **本方不代有权通道所有者**。不代评估暴露面、不代决定访问控制、不代出具访问记录、不代确定受控交付通道。以上均为 `PENDING_CHANNEL_OWNER_DECISION`，本方在其书面确认前不擅自执行、不追问通道。
