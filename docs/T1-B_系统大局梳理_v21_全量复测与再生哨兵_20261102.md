### 3.2 🔴 我方自测发现并修正的缺陷（如实披露，不掩饰）

初版哨兵以「读 `A1:C12000` 的 values 再 trim 尾部空行」确定末行 → 得到的末行**小于**服务端权威 `lastRow=11,380`，即**尾部若干行永远监控不到**，构成哨兵盲区。

- 根因：`inspectWorkbook` 对超大 range 的 `values` 返回会被截断，**不能作为末行依据**。
- 修正：改以服务端 `mode:'meta'` 返回的 `lastRow` 为末行（权威、不依赖 values 完整性），并加下限校验（`lastRow < 11000` ⇒ 拒绝结论）。
- 修正后复核：末页 `A11002:O11380` 返回 379 行（expect=379，无短页），末行 11,380 = `Jerry Fu / TS-2515F5125D6F`，确已完整读入。
- **修正后重测结论不变**：重复组仍为 **0**。

此缺陷为我方自测发现，非你方指出；仍如实入册，供你方复核修正是否到位。

### 3.3 哨兵的能力边界（不做过度声称）

- 哨兵**只能观测「是否已长回来」，不能防止它长回来**，也**不构成止血证明**。
